## 📌 About the Project

**NumPy Analyzer** is a menu-driven Python application built with the
**NumPy** library. It allows users to create 1D, 2D, and 3D arrays and
perform different operations on them through a simple command-line
interface.

The project practices Python concepts such as **classes, objects,
constructors, class methods, static methods, and private methods**.

## ✨ Features

### 🧱 Array Creation

-   Create 1D, 2D, and 3D NumPy arrays.
-   Enter array elements manually.
-   Validate the number of elements before creating an array.

### 🔍 Indexing & Slicing

-   Access individual elements, rows, columns, or depths.
-   Select a specific range of array elements.

### ➕ Mathematical Operations

-   Addition, subtraction, multiplication, and division.
-   Dot Product and Matrix Multiplication.

### 🔗 Combine & Split Arrays

-   Combine arrays.
-   Split an array into multiple parts.

### 🔎 Search, Sort & Filter

-   Search for a value and display its index.
-   Sort array values in ascending or descending order.
-   Filter values using comparison conditions.

### 📊 Aggregates & Statistics

-   Sum, Mean, Median
-   Standard Deviation and Variance
-   Minimum and Maximum
-   Percentile
-   Correlation Coefficient

## 🛠️ Technologies Used

-   **Python** -- Programming language
-   **NumPy** -- Numerical computing and array operations

## ⚙️ Installation & Setup

### 1. Check Python

Make sure Python is installed:

``` bash
python --version
```

### 2. Install NumPy

Open CMD or Terminal and run:

``` bash
pip install numpy
```

### 3. Run the Project

Open CMD or Terminal in the project folder and run:

``` bash
python Project-8.py
```

## ▶️ How to Use

1.  Run the Python file.
2.  Choose **Create a NumPy Array**.
3.  Select the array type: 1D, 2D, or 3D.
4.  Enter the dimensions and array elements.
5.  Select an operation from the main menu.
6.  Follow the on-screen instructions.
7.  Choose **Exit** when finished.

> 💡 Create an array first before selecting the other main-menu
> operations.

## ⚠️ Notes

-   Enter numeric values separated by spaces when prompted.
-   Enter the correct number of elements for the selected dimensions.
-   Division by zero is not allowed.
-   Dot Product and Matrix Multiplication require a 2D array.
-   For indexing, pressing **Enter** selects all available positions.
-   For slicing, use the `start:end` format, such as `0:2`.

## 🎯 Project Objective

The objective of this project is to practice Python object-oriented
programming and understand how NumPy can be used to create, manipulate,
and analyze multidimensional arrays.
