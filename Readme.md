# 📊 Data Analyzer and Transformer Program

> 🐍 A simple and beginner-friendly Python program for analyzing, filtering, sorting, and transforming numerical data.

---

## 🌟 About the Project

**Data Analyzer and Transformer Program** is a menu-driven Python project designed to demonstrate useful Python concepts in a simple and practical way.

The program allows you to enter a 1D dataset and perform different operations such as finding the minimum and maximum values, calculating the sum and average, finding factorials using recursion, filtering values with a lambda function, sorting data, and displaying dataset statistics.

The project uses a simple command-line interface and is suitable for beginners who are learning Python functions and built-in operations. fileciteturn0file0L7-L17

---

## ✨ Features

| 🔢 Option | 🚀 Feature | 📝 Description |
|---|---|---|
| 1️⃣ | 📥 Input Data | Enter numerical data separated by spaces |
| 2️⃣ | 📋 Data Summary | Shows total elements, minimum, maximum, sum, and average |
| 3️⃣ | 🧮 Factorial | Calculates factorial using recursion |
| 4️⃣ | 🔎 Filter Data | Filters values using a lambda function |
| 5️⃣ | 🔃 Sort Data | Sorts data in ascending or descending order |
| 6️⃣ | 📊 Statistics | Returns minimum, maximum, total, and average |
| 7️⃣ | 🚪 Exit | Closes the program |

## 🧠 Python Concepts Used

### 🔹 Built-in Functions
The project uses functions such as:

- `len()` 📏
- `min()` ⬇️
- `max()` ⬆️
- `sum()` ➕
- `round()` 🎯
- `sorted()` 🔃

The data summary calculates the number of elements, minimum, maximum, total, and average values. fileciteturn0file0L25-L35

### 🔹 Recursion
The factorial feature defines a `factorial()` function that calls itself until the base condition is reached. 🔁🧮 fileciteturn0file0L37-L46

### 🔹 Lambda Function
The filtering feature uses `filter()` with a lambda function to keep values greater than or equal to the selected threshold. 🔎✨ fileciteturn0file0L48-L60

### 🔹 Sorting
The program provides two sorting choices:

- 📈 Ascending order
- 📉 Descending order

It uses Python's `sorted()` function for both options. fileciteturn0file0L62-L84

### 🔹 Multiple Return Values
The `statistics()` function returns four values:

- Minimum
- Maximum
- Total
