# 📔 Personal Journal Manager

> 🐍 A simple Python console project for creating, viewing, searching, and deleting journal entries.

---

## 🌟 Project Overview

**Personal Journal Manager** is a beginner-friendly Python project that allows users to manage personal journal entries directly from the console.

### ✨ Main Options

- ✍️ Add a New Entry
- 📖 View All Entries
- 🔍 Search for an Entry
- 🗑️ Delete All Entries
- 🚪 Exit

The program displays these five options through its main menu. fileciteturn1file0L4-L11

---

## ✨ Features

### ✍️ Add a New Entry
Enter your journal entry and save it into `journal.txt`. The program uses append mode to add the new entry to the file. fileciteturn1file0L13-L19

### 📖 View All Entries
Reads `journal.txt` and displays all saved journal entries. fileciteturn1file0L21-L26

### 🔍 Search for an Entry
Enter a word to search for. The program checks the journal entries and displays matching entries. fileciteturn1file0L28-L35

### 🗑️ Delete All Entries
Clears the contents of `journal.txt`. fileciteturn1file0L38-L42

### 🚪 Exit
Select option `5` to exit the program. fileciteturn1file0L44-L49
