# 🧠 Personal Data Collector

> ✨ A simple and interactive Python project that collects personal information, displays Python data types and object IDs, and estimates the user's birth year.

## 🚀 Project Overview

**Personal Data Collector** is a beginner-friendly Python program designed to demonstrate:

- 🧑 User input with `input()`
- 🔢 Type conversion using `int()` and `float()`
- 🧩 Python data types
- 🆔 Object identity using `id()`
- 📅 Basic arithmetic for approximate birth-year calculation
- 💬 Interactive console output

## ✨ Features

| Feature | Description |
|---|---|
| 🧑 Name | Collects the user's name |
| 🎂 Age | Takes age as an integer |
| 📏 Height | Takes height in meters |
| 🔢 Favorite Number | Stores a favorite number |
| 🧠 Type Display | Shows the type of each value |
| 🆔 ID Display | Shows the Python object ID |
| 📅 Birth Year | Calculates an approximate birth year |

## 🛠️ Technologies Used

- 🐍 **Python 3**
- 💻 **Command Line / Terminal**
- 📚 Python built-in functions: `input()`, `int()`, `float()`, `type()`, `id()`

## 🧩 Concepts Demonstrated

### 🔹 User Input
The project uses `input()` to interact with the user.

### 🔹 Type Conversion
- `int()` converts input into integers.
- `float()` converts input into decimal numbers.

### 🔹 Python Type & Identity
The program uses `type()` to identify the data type and `id()` to display the object's identity.

### 🔹 Basic Calculation
The approximate birth year is calculated from the age using the current year represented in the program.
